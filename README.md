# SIREN AI 2.1

Локальная программа для подготовки понятных инструкций сотрудникам контактного центра и клиентам. ИИ отбирает сведения по заданной теме, сопоставляет материалы и предлагает текст в структуре «Было / Стало / Действия / Подсказки».

## Скачать и запустить

1. Откройте [выпуск 2.1.0](https://github.com/SafonovE/SIREN-AI/releases/tag/v2.1.0) и скачайте `SIREN-AI-2.1.0-Windows-x64.zip`.
2. Полностью распакуйте архив в отдельную папку на компьютере с Windows x64.
3. Дважды нажмите **Siren AI.exe**. Программа откроется в браузере и работает через локальный сервер.
4. Нажмите **«Заполнить с ИИ»**, настройте подключение и укажите установленную модель.

Node.js и средства чтения PDF включены в сборку. Установка Node.js отдельно не нужна. Модели ИИ в архив не входят. Для Ollama нужно отдельно запустить Ollama и установить выбранную модель; обычный локальный адрес — `http://127.0.0.1:11434`, ключ API не требуется.

Запасной запуск — `run_app.bat`. Остановка локального сервера — `stop_app.bat`. Не перемещайте отдельный EXE без остальных файлов программы.

## Подготовить инструкцию

1. Укажите **тему инструкции**: какое изменение нужно объяснить. В полях **«Что раскрыть»** и **«Что исключить»** задайте границы.
2. Добавьте документы, изображения или текст. Укажите роли материалов и скриншотов «Было» и «Стало».
3. Запустите анализ. Программа сохраняет этапы и обрабатывает большие материалы частями.
4. При существенных противоречиях ответьте на короткие вопросы или явно продолжите с отмеченными пробелами.
5. Прочитайте цельную инструкцию и готовый текст для клиента, сверьте основания, затем выберите поля для переноса в черновик.

Например, для учебного сценария: тема — «Счётчик активных обращений на кнопке “Обращения”»; раскрыть — «Как было, что изменилось, польза и ограничения»; исключить — «Другие изменения экрана». Тема задаёт отбор, но сама не подтверждает факты.

Материалы и цитаты используются как источники сведений, а не как команды для ИИ. Предложения по теме требуют проверки автора и не выбираются автоматически. Возможны ошибки модели, пропуски и неоднозначное распознавание изображений; успешное подключение к модели не гарантирует качество инструкции.

## Что нового в 2.1

- Тема и границы передаются на этапы отбора фактов, сопоставления материалов, составления и проверки текста.
- Одна связная инструкция и отдельный готовый текст для клиента.
- До трёх коротких уточнений по существенным противоречиям.
- Проверка оснований, числовых условий, посторонних утверждений и пропусков.
- Понятные карточки ошибок с действием **«Повторить незавершённое»** и необязательными **«Подробностями для поддержки»**.
- Автоматическое исправление неверных ссылок на текст, ограниченное разбиение сложных фрагментов и сохранение проверенных ответов.
- Сохранение готовых материалов и прежнего результата при продолжении; смена модели для незавершённой работы не удаляет готовые материалы.

## Если обработка прервалась

Откройте сохранённую обработку и нажмите **«Повторить незавершённое»**. После обычной остановки доступно **«Продолжить незавершённое»**. Готовые этапы используются повторно, если проходят текущую проверку.

Если ответ ИИ не удалось проверить, указывать номера строк или редактировать исходный документ не требуется. Программа попробует исправить ответ и уменьшить проблемный фрагмент. При повторной неудаче откройте **«Настройки обработки»**, выберите другую модель и нажмите **«Сохранить настройки для продолжения»**. Прежний результат доступен с предупреждением, если новая попытка ещё не завершена.

Обновление страницы или закрытие окна помощника не останавливает сервер. При выключении компьютера обработка остановится и продолжится после нового запуска и явного нажатия кнопки. Кнопка **«Приостановить»** прерывает текущий запрос.

## Материалы и подключения

Поддерживаются PNG, JPEG, WebP, PDF, DOCX, PPTX, XLSX, CSV, TXT и Markdown. До 2000 материалов / 10 ГБ на обработку, до 100 МБ на файл. Существуют ограничения извлечения текста, памяти и контекста модели; для больших наборов потребуется дополнительное место на диске и время.

В автоматическом режиме изображение передаётся модели с поддержкой изображений; при некоторых сбоях используется локально распознанный текст с предупреждением. Для анализа расположения элементов и графики добавьте важные изображения отдельно и проверьте результат по оригиналу.

Поддерживаются локальные, корпоративные и внешние API. В настройках можно импортировать пример cURL: команда разбирается для заполнения полей и не выполняется. Ожидание одного ответа — от 1 до 60 минут; общий лимит `0` означает отсутствие общего ограничения. Увеличение таймаута не ускоряет локальную модель.

## Данные и конфиденциальность

Настройки и сохранённые обработки версии 2.1 хранятся в `%LOCALAPPDATA%\SirenAI-v2.1`. Это отдельная папка от версии 2.0. Материалы и результаты остаются на компьютере до удаления обработки; удаление сохранённой обработки не удаляет исходные файлы.

При выборе внешнего провайдера материалы отправляются этому провайдеру после локальной проверки и подтверждения пользователя. Автоматического перехода с локальной модели на облачную нет. Ключ по умолчанию хранится в памяти серверного процесса; сохранение ключа использует Windows DPAPI текущего пользователя.

В публичной сборке оставлен только учебный пример с вымышленными данными. Пользовательские документы, скриншоты, настройки, журналы, тесты и результаты проверок в сборку не включены.

Сторонние компоненты и сведения об их лицензиях перечислены в `THIRD_PARTY_NOTICES.txt`.
